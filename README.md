Entry for the [make.fun competition "The plan make.fun will carry out in public"](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138).

## What it does

`main.py` (Python 3.13, no network) writes one plan to `/output/entry.txt`:
a done-for-you AI service sold to local plumbers — automated missed-call
text-back plus Google review replies at $149/month. Clients are found via
Google Maps and cold email, the $100 goes to a Twilio number and an
outreach tool, and the plan closes 3 clients by day 14 for $447/month
recurring. The edge: boring local niches, not the saturated AI-agency
gold rush.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is a fixed 274-character plan, byte-identical on every run.
